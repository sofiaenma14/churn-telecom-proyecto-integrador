# Cuadernos

Se ejecutan de inicio a fin en Google Colab, sin pasos manuales. Orden de ejecución:

1. `01_carga_datos.ipynb`: carga el dataset, verifica el archivo (SHA256, filas y columnas) y calcula la línea base de 26.54 %.
2. `02_comprension_preparacion.ipynb`: explora la calidad de los datos, aplica y justifica las decisiones de preparación y guarda las particiones de entrenamiento y prueba.

Ambos usan semilla fija (42) y rutas relativas
