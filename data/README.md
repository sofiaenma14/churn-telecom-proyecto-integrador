# Datos

Dataset del proyecto y su documentación.

- `WA_Fn-UseC_-Telco-Customer-Churn.csv`: Telco Customer Churn (Kaggle, BlastChar; datos de ejemplo de IBM), obtenido el 22/10/2026. 7 043 clientes y 21 columnas.
